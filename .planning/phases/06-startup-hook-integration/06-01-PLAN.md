2. Train/test split: `train_test_split(df["string"], df["label"], test_size=0.2, stratify=df["label"], random_state=42)`
3. Build Pipeline: `Pipeline([("tfidf", TfidfVectorizer(max_features=10000, ngram_range=(1, 2), min_df=2, max_df=0.95)), ("classifier", LGBMClassifier(random_state=42, verbose=-1))])`
4. Run RandomizedSearchCV with the existing param_distributions, n_iter=5, cv=2, scoring="accuracy", random_state=42, n_jobs=-1, verbose=1
5. Print training metrics: accuracy, classification report, best hyperparameters (same print statements currently in __main__)
6. Save model: `joblib.dump(best_model, model_path)` where `model_path = Path(__file__).parent / "model.pkl"`
7. Print "Model saved to {model_path}"
8. Verify: load the saved model, predict on a test sample, assert correctness
9. Print "Model verification passed"
10. `return model_path`
