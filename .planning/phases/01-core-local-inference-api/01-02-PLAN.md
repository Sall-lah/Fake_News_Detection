  <action>
    Create app.py with Flask app:
    - `from flask import Flask, request, jsonify`
    - `from preprocess import clean_text`
    - `from model import get_model`
    - `app = Flask(__name__)`
    Define route:
    ```python
    @app.post("/predict")
    def predict():
        payload = request.get_json(silent=True) or {}
        title = payload.get("title") or ""
        text = payload.get("text") or ""
        cleaned = clean_text(title, text)
        if not cleaned:
            return jsonify({"status": "error", "message": "cleaned input is empty"}), 400
        model = get_model()
        if model is None:
            return jsonify({"status": "error", "message": "model not loaded"}), 503
        try:
            prediction = model.predict([cleaned])[0]
        except Exception:
            return jsonify({"status": "error", "message": "prediction failed"}), 500
        label = "true" if str(prediction).lower() in ("1", "true", "real") else "fake"
        return jsonify({"status": "ok", "label": label}), 200
    ```
    Ensure error responses match D-02 and success payload matches D-01. Do not include model filename in any error message (D-06).
  </action>
