1. Check if `model_path` exists using `model_path.exists()` (per D-02 — only check existence, don't catch corruption).
2. If the file does NOT exist: print an info message `"No model found at {model_path} — training will run on startup"` (per D-04), return `None` (per D-01).
3. If the file exists: call `joblib.load(model_path)`, assign result to global `MODEL`, and return `MODEL`.
4. Do NOT wrap `joblib.load` in a try/except — let exceptions bubble up (per D-02: corrupted or version-mismatched files should crash, not silently return None).

```python
def load_model(model_path: Path) -> object | None:
    global MODEL
    if not model_path.exists():
        print(f"No model found at {model_path} — training will run on startup")
        return None
    MODEL = joblib.load(model_path)
    return MODEL
```
