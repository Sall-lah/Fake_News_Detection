Rewrite the Dockerfile with these changes:

1. Keep base image: `FROM python:3.13-slim`
2. Keep WORKDIR: `WORKDIR /app`
3. Keep dependency layer caching: `COPY requirements.txt .` then `RUN pip install --no-cache-dir -r requirements.txt`
4. CHANGE: Replace `COPY model.pkl .` with `COPY dataset/ ./dataset/` — copy the dataset directory into the image (per D-01, D-02: no model.pkl baked in, dataset available for runtime training)
5. Keep code COPY: `COPY app.py model.py preprocess.py train.py ./` — include train.py so the lazy import `from train import train` in app.py works inside the container
6. Keep EXPOSE: `EXPOSE 5000`
7. Keep CMD: `CMD ["python", "-m", "flask", "run", "--host=0.0.0.0", "--port=5000"]` (per D-03: Flask dev server, no Waitress/gunicorn)

The full Dockerfile should be:
```dockerfile
FROM python:3.13-slim

WORKDIR /app

# Install dependencies first (layer caching)
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# Copy dataset (model is trained at runtime, not baked into image)
COPY dataset/ ./dataset/

# Copy application code (include train.py for startup training)
COPY app.py model.py preprocess.py train.py ./

EXPOSE 5000

# Use Flask dev server for local development
CMD ["python", "-m", "flask", "run", "--host=0.0.0.0", "--port=5000"]
```
