<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| DataFrame → Pipeline.fit() | Training data flows into model; corrupted data produces wrong model |
| Pipeline → joblib.dump | Serialized model written to local filesystem |
| joblib.load → predict() | Deserialized model used for inference |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-04 | Tampering | model.pkl file | accept | Local-only file; no network exposure. User responsible for filesystem integrity. |
| T-05-05 | Spoofing | joblib.load(model.pkl) | mitigate | joblib.load can execute arbitrary code during deserialization. Mitigation: Only load model.pkl from trusted local path (Path(__file__).parent / "model.pkl"), never from user input or network source. Document this trust boundary. |
| T-05-06 | Repudiation | Training metrics output | accept | Local console output only; no audit trail required for local API. |
| T-05-07 | Denial of Service | RandomizedSearchCV execution | accept | Local script; resource exhaustion only affects local machine. n_iter=5, cv=2 limits compute time. |
</threat_model>
